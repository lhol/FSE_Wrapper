- Publishing uses a credential (API key) stored as a GitHub secret and configured in `release.yaml`
- **No additional nuget.org setup is required in this release**
- Document the existing setup clearly in README so it is not accidentally duplicated

### NuGet — GitHub Packages ❌ MISSING
- NuGet packages do **not** appear at https://github.com/lhol/FSE_Wrapper/packages
- Root cause: `github.com/{owner}/{repo}/packages` shows the **GitHub Packages registry**
  (feed URL: `https://nuget.pkg.github.com/lhol/index.json`) — this is a completely separate
  registry from nuget.org. Publishing to nuget.org does not populate GitHub Packages.
- Fix: add a second `dotnet nuget push` step in `release.yaml` targeting the GitHub Packages feed
- Authentication uses the built-in `GITHUB_TOKEN` — no extra secrets required
- The workflow already has `contents: write` permission; add `packages: write` permission
- Benefit: packages become discoverable directly from the GitHub repository page
