## Issues to Fix / Features to Add

- Set up OSSRH (Sonatype) account and signing keys
- Configure `maven-gpg-plugin` and `nexus-staging-maven-plugin` in pom.xml
- Add GitHub Actions workflow step that publishes on `v*.*.*` tag
- Include Javadoc and sources JAR (required by Maven Central)
- Publish `org.karenta:FSE_Wrapper-panama` (Panama JAR) alongside the JNI JAR

- `Huff0.Net` and `Fse.Net` are already published to nuget.org on every `v*.*.*` tag
- Publishing uses a credential (API key) stored as a GitHub secret and configured in `release.yaml`
- **No additional NuGet setup is required in this release**
- Document the existing setup clearly in README so it is not accidentally duplicated
